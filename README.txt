GYMTRACK - prototipo funcional

Abre index.html en el navegador. Los datos se guardan en localStorage.

Incluye:
- Dashboard
- Registro de entrenamientos
- Series, kg, reps y RPE
- Historial
- Rutinas
- Catálogo de ejercicios
- Volumen y estadísticas básicas

schema.sql contiene una base inicial para migrar a Supabase/PostgreSQL con usuarios.
